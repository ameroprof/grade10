# لعبة مهارة محللي البيانات

لعبة تعليمية عربية للصف العاشر الأساسي في مادة المهارات الرقمية، مبنية على وحدة تحليل البيانات والتمثيل المرئي وفق محتوى البروميت.

## المميزات
- عالم ثلاثي الأبعاد مبسط يستكشف فيه الطالب مناطق مختلفة.
- 7 مناطق تعليمية مترابطة + مشروع ختامي.
- نظام XP وشارات ومراحل تعليمية.
- مختبرات تفاعلية للرسوم البيانية، التنظيف، الدوال، التنبؤ، والتقرير النهائي.
- حفظ التقدم محليًا عبر LocalStorage.
- تقرير تقييم قابل للطباعة مع شهادة إنجاز وملاحظات المعلم.

## التشغيل محليًا
1. تثبيت الاعتماديات:
   ```bash
   npm install
   ```
2. تشغيل التطبيق في وضع التطوير:
   ```bash
   npm run dev -- --host 0.0.0.0
   ```
3. افتح الرابط المعروض في المتصفح، عادةً:
   ```text
   http://localhost:5173/
   ```

## البناء للإنتاج
```bash
npm run build
```

## النشر على GitHub Pages

يُبنى التطبيق تلقائيًا وينشر إلى GitHub Pages عند دفع تغييرات إلى فرع `main` باستخدام GitHub Actions.

1. ارفع ملفات المشروع إلى مستودع GitHub باسم `grade10` وعلى فرع `main`.
2. من صفحة المستودع افتح **Settings → Pages**.
3. اختر **GitHub Actions** من **Build and deployment → Source**.
4. بعد نجاح سير العمل **Deploy to GitHub Pages**، سيكون رابط التطبيق:
   ```text
   https://ameroprof.github.io/grade10/
   ```

إعداد Vite يضبط المسار الفرعي الخاص بالمستودع عند البناء في GitHub Actions، مع إبقاء عنوان التطوير المحلي على جذر الموقع.

قبل جعل المستودع عامًا، راجع الملفات التي ستُنشر. ملف `.gitignore` يستبعد الاعتماديات وملفات البناء والملفات المؤقتة وملفات PDF الموجودة في جذر المشروع.

## ملاحظات
- المشروع مصمم ليعمل مباشرة في المتصفح دون خادم خلفي.
- جميع البيانات المستخدمة تعليمية ومصطنعة، ولا تستخدم بيانات شخصية حقيقية.
